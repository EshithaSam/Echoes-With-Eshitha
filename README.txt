# Echoes with Eshitha website

A responsive single-page website using the mint, navy, periwinkle, warm yellow, and cream palette from your reference image.

## Preview locally
Open `index.html` in a web browser.

## Publish to echoeswitheshitha.com
This package is the website files; it does not publish the site or configure your domain automatically.
1. Choose a static website host (for example, Netlify, GitHub Pages, or your existing domain host).
2. Upload/deploy `index.html` (or the folder contents).
3. In the host's domain settings, add `echoeswitheshitha.com` and follow its DNS instructions at your domain registrar.
4. Enable HTTPS after DNS is verified.

## Before publishing
- Confirm that the phone number and email are correct.
- Add your session format, fees, availability, cancellation policy, and professional credentials if you want them public.
- The enquiry form opens the visitor's email app; it does not store submissions or send them to a server.
- Review the wording of all services so the website accurately reflects the services you currently offer.
